# Code de conduite

Adapté du [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Notre engagement

Ce dépôt est un espace d'apprentissage. Chacun doit pouvoir y contribuer sans craindre le
mépris : débutant, étudiant, professionnel, quel que soit le niveau, le genre, l'origine,
la langue ou l'expérience.

## Comportements attendus

- Critiquer **le contenu**, jamais la personne. Une commande fausse n'est pas une faute morale.
- Expliquer plutôt que corriger sèchement : un commentaire de review doit être actionnable.
- Respecter l'éthique du dépôt : uniquement des cibles légales, aucun contenu facilitant
  l'attaque de systèmes sans autorisation.
- Accepter qu'un writeup soit reformulé, réorganisé ou refusé pour des raisons de structure.

## Comportements inacceptables

- Insultes, harcèlement, commentaires dégradants, attaques personnelles.
- Publication de données personnelles d'autrui (doxxing), de flags de challenges actifs ou de
  credentials.
- Contenu illégal, ou sollicitation pour attaquer un système réel.
- Spam, autopromotion hors sujet.

## Application

Un manquement peut être signalé au mainteneur du dépôt (voir [`.github/MAINTAINERS`](.github/MAINTAINERS)).
Selon la gravité : rappel, demande de modification, fermeture de la PR, blocage du compte.

Les signalements sont traités de manière confidentielle.
